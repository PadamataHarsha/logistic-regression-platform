A PRACTICAL MODELING STUDY

From visitor signals to a probability.

A beginner-friendly look at a small Logistic Regression project.

PROJECT OBJECTIVE

Can browsing context help estimate an ad click?

This project applies Logistic Regression to an advertising dataset. It studies five numeric visitor features and predicts the dataset's Clicked on Ad target. The web app makes the existing training workflow inspectable and lets an authenticated user try a single profile.

THE METHOD

What Logistic Regression does

Despite its name, Logistic Regression is commonly used for classification. It combines weighted inputs, passes the result through a probability function, and estimates the chance of each class. The selected class is the one with the larger estimated probability.

The original workflow standardizes the five inputs with StandardScaler, then fits LogisticRegression(max_iter=1000, random_state=42). A stratified 70/30 split keeps the class proportions similar in training and test data.
